# Frontend - React + Vite

Aplikasi frontend untuk generator prediksi visa toto.

## Setup

```bash
npm install
npm run dev
```

Aplikasi akan berjalan di `http://localhost:3000`

## Build

```bash
npm run build
```

Hasil build ada di folder `dist/`

## Features

- Upload custom background image
- Select date dan pasaran
- Generate single atau batch
- Live preview hasil
- Download ZIP untuk batch
